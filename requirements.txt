# Runtime dependencies: the WHOLE resolved set, every package the panel imports at runtime and
# everything those pull in, pinned to exact versions. Pinning only the direct dependencies left the
# rest to float. install.sh skips pip when this file is unchanged, and `pip install -r` never
# upgrades a package that already satisfies a range. So a security fix in a transitive package
# (Werkzeug, python-engineio, Jinja2, ...) never reached an installed host. Dependabot proposed no
# bump for a package it could not see, and pip-audit checked a freshly resolved set that no host ran.
#
# With every package listed, a bump to any of them changes this file. That makes install.sh re-run
# pip, gives Dependabot something to propose (grouped pip updates, reviewed), and makes pip-audit
# read the set that is deployed. tests/unit checks that the list stays closed: each package's own
# requirements, for CPython 3.10-3.14 on Linux, must be pinned here too.
