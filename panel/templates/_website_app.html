{# A Node.js app: version, build and start commands, its port, and environment variables (stored encrypted, write-only: the page gets their names, never their values). #}
Environment variables
Stored encrypted and never shown again. Leave a saved value empty to keep it.

The app runs in its own container from an official Node.js image, not on the host's Node.js: that copy is shared with the panel, and the container keeps this site's limits and network rules. The build may reach the npm registry; the running app has no internet access unless an administrator allows it.
