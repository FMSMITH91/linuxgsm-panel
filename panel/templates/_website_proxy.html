{# The web proxy and how visitors reach the sites (superadmin only: it changes a root service and the public listener). Exposure is a proxy-wide choice per host: Public, Restricted (an allow list, with Cloudflare's networks one tap away), or Tunnel (no inbound port; a token). The token is write-only: the page is told only whether one is saved. The security settings below show OWASP's recommended value beside each field and a note, never a block, when a value is outside it (js/websites_proxy.js). #}
