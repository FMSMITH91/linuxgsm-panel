Databases need a database server on this host.

Installs MariaDB from Ubuntu, listening on this machine only. It is kept up to date by OS updates.

Ask an administrator to set up databases on this host.

A database server is already running here, but the panel can't sign in to it yet. Enter an admin login that can create users and grant them rights. The panel keeps it encrypted.

Enter an admin login to replace the stored one, or clear it to have the panel sign in as root over the socket again.

Each backup of this server also saves its databases into its files (panel-db-dumps), so restoring the backup brings them back with Restore from dump. Changes made while the backup stops and archives the server are not in it.
