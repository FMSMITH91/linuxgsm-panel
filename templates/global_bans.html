A SteamID added here is banned on every Source / GoldSrc server, across all your hosts, that is running when you add it. It's applied through each server's own console, using the game's native banid and writeid commands, so it uses the game's own ban list and survives restarts. A server that is stopped or unreachable at that moment does not get it. Press Sync to all servers while it is running to apply the whole list to it.
